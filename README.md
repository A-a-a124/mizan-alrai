# ميزان الريع · Mizan Al-Rai
### منصة التنبؤ الذكي بالتدفقات المالية للوقف
**Smart forecasting of waqf yields, sustainable spending and masarif allocation**

> **لماذا «ميزان الريع»؟** الريع هو غلّة الوقف وعائده، وهو ما نحلّله ونتنبأ به. والميزان هو القرار نفسه: موازنة ما يُصرف للمستحقين اليوم بما يُحفظ من الأصل للأجيال القادمة.

**🔗 الموقع (يفتح عند أي أحد):** https://a-a-a124.github.io/mizan-alrai/ · [محاكي القرار](https://a-a-a124.github.io/mizan-alrai/dashboard/) · [الملخص التنفيذي PDF](https://a-a-a124.github.io/mizan-alrai/report/executive_summary.pdf)

## التشغيل (Python 3.12)

```bash
pip install -r requirements.txt
```

```bash
python scripts/run_analysis.py
```

```bash
python -m pytest -q
```

| الأمر | ماذا يفعل | المدة |
|---|---|---|
| `python scripts/run_analysis.py` | يعيد بناء `data_clean/` و`outputs/` و`dashboard/data.js` من البيانات الخام | ≈ 5 ث |
| `python scripts/build_notebook.py` | يولّد `analysis.ipynb` وينفّذه كاملاً (السرد العربي فوق الكود نفسه) | ≈ 30 ث |
| `python scripts/build_report.py` | يولّد `report/executive_summary.pdf` من الجداول (يتطلب Edge أو Chrome) | ≈ 10 ث |
| `python scripts/build_site.py` | يولّد صفحة الموقع `index.html` (GitHub Pages) من الجداول | < 1 ث |
| `python -m pytest -q` | 28 اختباراً: سلامة البيانات، التنظيف، عدم تسرب المستقبل، قيود التوزيع | ≈ 4 ث |

لا يحتاج التشغيل إلى إنترنت؛ اللقطات الخام محفوظة في `data_raw/` ومحمية بفحوص سلامة.
لوحة القرار التفاعلية: افتح `dashboard/index.html` عبر خادم محلي (`python -m http.server --directory dashboard`) ثم `http://localhost:8000`.

**طريقة الجمع (29 أكتوبر 2026):** البوابتان تحجبان الطلبات الآلية (WAF)، فقُرئت البيانات من واجهات المعاينة الرسمية داخل متصفح ثم حُفظت كلقطات.
جداول المصارف عمودان فقط (المنطقة، المصرف) بلا معرّفات، فخُزّنت كعدّادات (منطقة، مصرف، عدد) دون فقدان أي معلومة.
أسعار تداول خُزّنت كآخر تقييم في كل شهر. وأُسقط حقل «صافي الأصول» لأنه صفر في أغلب الأشهر.

## المنهجية باختصار

1. **التنظيف** (`src/waqf/clean.py`): 12 قاعدة موثقة في `outputs/tables/cleaning_log.csv`، منها: طيّ إملائي عربي وقاموس مصارف (25 تسمية خام ← 24 مصرفاً)، وإزالة BOM، وتحويل الأرقام النصية، وحذف أسعار ما قبل الاستثمار، ومعالجة الأسعار المتجمدة، واستيفاء الفجوات الربعية مع تعليمها، واستبعاد الصناديق الأقصر من 12 شهراً، وفصل الصناديق الموزِّعة.
2. **كشف التوزيعات المخفية** (`index.py`): هبوط سعر صندوق بأكثر من 2% بينما صناديق المديرين الآخرين أعلى منه بـ3 نقاط فأكثر = توزيع على المستفيدين. رُصد 25 حدثاً، منها نمط يوليو المتكرر في صناديق الإنماء. حجم التوزيع = الفجوة عن الأقران.
3. **المؤشر:** متوسط متساوي الأوزان للعوائد اللوغاريتمية الشهرية لـ12 صندوقاً تراكمياً، بنسختين: السعر فقط، والعائد الكلي المقدَّر.
4. **التنبؤ** (`forecast.py`): 5 نماذج (عائد صفري، متوسط تاريخي، متوسط 36 شهراً، تمهيد أسي مخمَّد، ARIMA) على 36 نقطة انطلاق خارج العينة. الفائز «متوسط 36 شهراً» بخطأ أقل بـ36% من المرجع الساذج. النطاق من أخطاء الاختبار الرجعي نفسها.
5. **الصرف المستدام** (`risk.py`): Bootstrap كتلي ثابت (Politis–Romano، متوسط الكتلة 6 أشهر، 10,000 مسار، 10 سنوات، بذرة 2026)، وقاعدة صرف ممهَّدة على 12 ربعاً. السقف = أعلى معدل يحقق احتمال حفظ القيمة الحقيقية ≥ الثقة المطلوبة.
6. **التوزيع** (`allocate.py`): عمارة الوقف 10% ← احتياطي استقرار حتى يغطي صرف سنة ← شروط الواقفين ثابتة ← حصة «أوجه البر» المرنة بأوزان أولوية معلنة مع حد أدنى 2%.

القرارات المعمارية موثقة في `.10x/adrs/001-*.md`.

## الحدود
- الصناديق المدرجة **وكيل** لأداء الاستثمار الوقفي، وليست القوائم المالية لوقف عائلي بعينه.
- السلاسل قصيرة (أطولها 84 شهراً)، والصناديق الحية فقط (تحيز بقاء)، وعولج ذلك بسيناريو ضغط بخصم 1% سنوياً.
- مبالغ التوزيع **مقدَّرة** لأن تداول لا ينشرها، والكشف حساس لعتبتين معلنتين في `index.py`.
- بيانات المستفيدين وطنية لثلاث سنوات فقط، فلا يوجد قياس للاحتياج حسب المنطقة. أوزان الأولوية افتراضات معلنة وقابلة للتعديل في اللوحة.
- التضخم معامل (2% افتراضياً) وليس توقعاً.
